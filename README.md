Descripció: El programa te una temepratura definida a 25 graus, i la imprimeix per pantalla. A la branca Fahrenheit, l'hem modificat i el programa converteix la temperatura en graus Fahrenheit, a més ho imprimeix per pantalla. A la branca Classificacio, la modificacio parteix del programa del main i imprimeix si la temperatura es alta o baixa, amb la condició que sigui major o igual a 20.

Instruccions:
1) ens posem a la branca que tingui la versio del programa que volguem compilar.
2) gcc -Wall -Wextra temperatura.c -o temperatura
3) ./temperatura
